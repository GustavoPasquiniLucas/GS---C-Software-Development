# 🌎 Sobre o Projeto

O SpaceAlert é uma aplicação desenvolvida em C# que transforma dados ambientais em alertas simples e acessíveis para produtores rurais e órgãos públicos.

O sistema simula dados de satélite relacionados à chuva, temperatura, umidade do solo e vegetação, gerando alertas que auxiliam na tomada de decisão.

---

# 🎯 Objetivo

Facilitar a interpretação de dados ambientais, transformando informações complexas em alertas claros sobre possíveis riscos, como enchentes, secas e degradação da vegetação.

---

# ⚙️ Funcionalidades

* Monitoramento de regiões
* Simulação de dados ambientais
* Geração automática de alertas
* Histórico de alertas
* Classificação de riscos
